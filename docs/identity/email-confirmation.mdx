---
title: Email Confirmation
---

Password sign-up creates:

- a `users` row with `email_confirmed_at = NULL`
- a `credentials` row
- one pending `email_confirmations` row with an HMAC-SHA256 code hash

Codes are 6 digits, expire after `EMAIL_CONFIRMATION_TTL_SECONDS`, and allow `EMAIL_CONFIRMATION_MAX_ATTEMPTS`. Resends are capped by `EMAIL_CONFIRMATION_RESEND_COOLDOWN_SECONDS` and `EMAIL_CONFIRMATION_RESEND_HOURLY_CAP`.

`MAIL_BACKEND=console` writes local messages to `MAIL_OUTBOX_DIR`. `MAIL_BACKEND=http` sends a vendor-neutral JSON envelope to `MAIL_HTTP_URL` with `MAIL_HTTP_API_KEY`.

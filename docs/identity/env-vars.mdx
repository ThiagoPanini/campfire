---
title: Identity Env Vars
---

Google:

- `GOOGLE_OAUTH_ENABLED` default `false`
- `GOOGLE_OAUTH_CLIENT_ID`
- `GOOGLE_OAUTH_CLIENT_SECRET`
- `GOOGLE_OAUTH_REDIRECT_URI`
- `WEB_BASE_URL` default `http://localhost:5173`
- `OAUTH_FLOW_HMAC_KEY` required before any production deploy
- `OAUTH_FLOW_TTL_SECONDS` default `600`
- `GOOGLE_STUB_ENABLED` default `false`

Trusted proxy resolution:

- `TRUSTED_PROXIES` comma-separated CIDR/IP allow-list. Leave empty locally to ignore `X-Forwarded-For`. Set explicit Render/proxy ranges per environment before relying on forwarded client IP rate limits.

Email confirmation:

- `EMAIL_CONFIRMATION_REQUIRED` default `true`. Set `false` only during a time-boxed mailer incident rollback; remove after stabilization.
- `EMAIL_CONFIRMATION_HMAC_KEY` required before any production deploy
- `EMAIL_CONFIRMATION_TTL_SECONDS` default `900`
- `EMAIL_CONFIRMATION_MAX_ATTEMPTS` default `5`
- `EMAIL_CONFIRMATION_RESEND_COOLDOWN_SECONDS` default `60`
- `EMAIL_CONFIRMATION_RESEND_HOURLY_CAP` default `3`

Mailer:

- `MAIL_BACKEND` default `console`
- `MAIL_FROM`
- `MAIL_OUTBOX_DIR` default `tmp/mail`
- `MAIL_HTTP_URL`
- `MAIL_HTTP_API_KEY`

---
title: Google OAuth
---

Local setup:

1. Create a Google Cloud sandbox project.
2. Configure OAuth consent with `openid`, email, and profile scopes.
3. Create a Web application OAuth client.
4. Add `http://localhost:8000/auth/google/callback` as an authorized redirect URI.

Required API env vars:

- `GOOGLE_OAUTH_ENABLED=true`
- `GOOGLE_OAUTH_CLIENT_ID`
- `GOOGLE_OAUTH_CLIENT_SECRET`
- `GOOGLE_OAUTH_REDIRECT_URI`
- `WEB_BASE_URL`
- `OAUTH_FLOW_HMAC_KEY`

Use one Google project/client per environment. If Google must be disabled, set `GOOGLE_OAUTH_ENABLED=false`; `/auth/config` reports disabled, the web button hides, and password auth keeps working.

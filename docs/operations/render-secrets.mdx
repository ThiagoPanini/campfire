---
title: Render Secrets
---

Set identity secrets in the Render dashboard, not in git.

Before deploying `campfire-api-prod`, set both HMAC keys first. Production startup fails closed when either is missing:

- `OAUTH_FLOW_HMAC_KEY`
- `EMAIL_CONFIRMATION_HMAC_KEY`

Use distinct values per environment for:

- `GOOGLE_OAUTH_CLIENT_SECRET`
- `OAUTH_FLOW_HMAC_KEY`
- `EMAIL_CONFIRMATION_HMAC_KEY`
- `MAIL_HTTP_API_KEY`

Set `TRUSTED_PROXIES` per environment before enabling proxy-aware auth rate limits. Keep it empty until the trusted proxy CIDRs/IPs are known.

Use separate Google OAuth clients for dev and prod. Production cookies should keep `REFRESH_COOKIE_SECURE=true` and `REFRESH_COOKIE_SAMESITE=none` when the web and API are cross-origin.
